# 房间界面 token

房间壳（`#room-view` 与图片查看器）的视觉事实源。数值来自 Grok 式稿子的 `shared.css`，不另猜一套。

## 复核

第一稿曾落到「近黑底 + 一根亮绿」的常见深色模板上。稿子写明底是纯黑 `#000`，强调色是系统蓝，主 Bot 是白鸟。所以底改回 `#000`，强调色只用 `#0a84ff`，绿只出现在「已允许」这一行状态上。每只 Bot 的颜色是身份，不是第二套强调色。

## 颜色

| 名字 | 值 | 用途 |
|---|---|---|
| `--bg` | `#000000` | 页面底 |
| `--surface` | `#1c1c1e` | 卡片、输入胶囊、侧栏搜索 |
| `--surface-2` | `#2c2c2e` | 用户气泡、拒绝按钮 |
| `--text` | `#f5f5f7` | 正文 |
| `--text-2` | `#a1a1a6` | 名字、预览、说明 |
| `--text-3` | `#636366` | 时间、占位 |
| `--accent` | `#0a84ff` | 允许按钮、选中字母、焦点环 |
| `--ok` | `#30d158` | 已允许 |
| `--danger` | `#ff453a` | 已拒绝 |
| `--warn` | `#ff9f0a` | 主 Bot 星标 |
| `--hairline` | `rgba(255,255,255,0.08)` | 卡片边 |

Bot 身体色（按 id 取一只，主 Bot 固定白）：`#bf5af2` `#ff9f0a` `#8e8e93` `#64d2ff` `#30d158` `#ac8e68` `#0a84ff` `#ff375f`，主 Bot `#f5f5f7`。

正文 `#f5f5f7` 在 `#000` 上对比度高于 15:1。次要字 `#a1a1a6` 在黑底上约为 7.4:1。时间 `#636366` 只用于 12px 的非正文时间，不拿来写句子。

## 字

一族：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Helvetica Neue", sans-serif`。

| 角色 | 大小 | 行高 | 字重 |
|---|---|---|---|
| 侧栏品牌 | 20px | 1.2 | 700 |
| 列表名、气泡、选项 | 16px | 1.45（气泡）/ 1.35（用户胶囊） | 600 / 400 |
| 顶栏胶囊、卡片标题 | 15px | 1.35 | 600 |
| 预览、说明、按钮 | 13px | 1.45 | 400 |
| 时间、图片说明 | 12px | 1.3 | 400 |

Bot 正文段落之间 8px。一行不超过约 70 个汉字宽度（桌面消息列最大 860px）。

## 间距

8pt：`4` 只用于字与字之间的光学缝（预览距名字），布局只用 `8 / 16 / 24 / 32 / 40 / 48`。

- 列表行：内边距 `8px 16px`，头像与文字间隙 `16px`，行圆角 `16px`
- 用户气泡：`8px 16px`，圆角 `24px`
- 卡片：内边距 `16px`，圆角 `16px`，按钮高 `40px`，按钮间隙 `8px`
- 顶栏：左右 `16px`，上下 `8px`
- 输入条：外边距 `8px 16px 16px`，胶囊高 `48px`

## 圆角

| 层级 | 半径 |
|---|---|
| 头像、图标钮、字母标、语音钮 | 全圆 |
| 用户气泡、输入胶囊、搜索 | `24px` |
| 图片、卡片、选项行 | `16px` |
| 拒绝/允许、字段块 | `16px` / `8px` |

## 动效

只响应用户动作：按下缩到 `0.97`，选项悬停铺一层 `rgba(255,255,255,0.04)`。打字三点是唯一循环动画。`prefers-reduced-motion: reduce` 时关掉位移动画和弹跳，状态变化仍在。
