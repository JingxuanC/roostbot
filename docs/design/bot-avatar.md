# Bot 头像：Roost 小鸟

> 状态：已实现（`apps/web/lib/bird.js`，2026-11-05）。
> 关系：`bot-identity.md` 定义身份/状态语义；本文只定义 Bot 的头像外观。人类账号仍用抽象 glyph。

## 1. 概念

Roost 是「栖木 / 鸟舍」：Bot 住在这里，所以 **Bot 就是鸟**。
头像不是插画、不是照片，而是**程序化小鸟**——圆身、喙、大眼、尾羽、爪，
用 SVG 画在 96×96 里，靠几何和配色区分个体。目标是 20px 时仍能一眼认出「这是一只鸟」。

**原创声明**：气质参考「一只圆滚滚、有表情的鸟」这一大众类型，不复制任何现有动画角色
（不照搬《Angry Birds》的角色轮廓、配色组合、眉眼或道具）。所有鸟形由本仓库几何路径生成。

## 2. 形状语言

| 部件 | 规则 | 作用 |
|---|---|---|
| 身体 | 近圆/蛋形，上窄下宽；物种微调宽高比 | 远看是「鸟」，不是图标 |
| 肚子 | 比身体浅一档的椭圆 | 体积感，深色主题下也可辨 |
| 眼睛 | 两个大眼白 + 深色瞳孔 + 高光；猫头鹰最大、乌鸦最小 | 表情的主要载体 |
| 喙 | 固定暖黄；尖/钩/扁/小四种 | 物种区分 + 与身体色对比 |
| 眉 | 平/柔/锐三种，按 id 稳定生成 | 每只鸟的「性格」 |
| 冠饰 | 公鸡红冠+肉垂、猫头鹰角羽、鹦鹉卷羽、乌鸦短簇、雏鸟绒羽 | 物种第一识别点 |
| 尾羽 | 短/羽束/长（乌鸦、鹦鹉） | 侧面轮廓 |
| 爪 | 两条暖黄短斜线 | 落地的感觉 |

## 3. 六个物种

| 物种 | 轮廓 | 特征 |
|---|---|---|
| 雏鸟 Chick | 高圆、短尾 | 三层绒羽、极小喙，最「小」 |
| 公鸡 Rooster | 标准圆、羽束尾 | 红色鸡冠 + 肉垂 |
| 猫头鹰 Owl | 宽扁、短尾 | 角羽 + 最大眼睛 |
| 乌鸦 Crow | 窄长、长尾 | 小眼、尖喙、短簇冠 |
| 鹦鹉 Parrot | 标准、长尾 | 钩喙 + 卷冠 |
| 鸭子 Duck | 宽扁、短尾 | 扁喙 |

## 4. 配色

复用品牌 8 色（与 glyph 相同）：amber / teal / blue / violet / rose / moss / clay / slate。
每色给出 `body` / `wing` / `belly` 三档；喙与爪固定 `#E9A23B`，眼白 `#FFFDF7`、瞳孔 `#26211C`。
深色与浅色主题都验证过：鸟身与背景、喙与鸟身、眼白与鸟身的对比度均足够。

## 5. 状态（只允许一种动画）

| 状态 | 表现 |
|---|---|
| `idle` | 正常站立 |
| `working` | 外圈 2.4s 呼吸环（唯一动画；`prefers-reduced-motion` 下静止） |
| `paused` | 整只去饱和（opacity 0.55），闭眼弧线 |
| `alert` | 眉眼上扬、瞳孔上移——「需要你」 |

**不做**：不闪、不跳、不在列表里同时动多个（安静优先，沿用 bot-identity §7）。

## 6. 尺寸与用法

- 20 / 24 / 32 / 40 / 64 五档；列表 24、侧栏 20–24、详情标题 40、头像编辑器预览 64。
- 生成规则：`birdSpecFor(id)` = fnv1a(id) → 物种(6) × 调色板(8) × 倾斜(3) × 眉形(3) × 脸颊标记(2)。
- **改名不改形象**：id 不变则鸟不变；换 `avatar.image` 上传图时优先用上传图。
- Bot 详情页的「随机预览」也走同一函数（基于 id），不会出现「预览和列表不是同一只鸟」。

## 7. 无障碍

- SVG `role="img"`，`aria-label` = Bot 名称（拿不到名称时才用「Bot 头像」）。
- 不只用颜色区分：物种轮廓 + 冠饰 + 眉形都不同。
- 关键形状用描边/对比度保证 20px 可读；不在 20px 下使用细线条表情。
- 动画尊重 `prefers-reduced-motion`。

## 8. 实现

- `apps/web/lib/bird.js`：`birdSpecFor(id)`、`birdSvg(id, {size, state, label})`、`BIRD_SPECIES/PALETTES/STATES`。
- `apps/web/lib/dom.js`：`botAvatar()` 无上传图时改用 `birdSvg`；人类 `avatar()` 仍用 glyph。
- `apps/web/styles.css`：`.bird-ring` 呼吸环 + reduced-motion。
- 测试：`apps/web/test/bird.test.ts`（确定性、物种/配色覆盖、状态、转义、尺寸回退）。
- 预览图：`docs/assets/bot-birds.png`（物种/配色/尺寸/状态/列表）、`docs/assets/bot-birds-app.png`（真实应用内）。
