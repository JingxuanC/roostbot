# 0001 — 项目名称：Roost Bot

- 状态：已定
- 日期：2026-11-03

## 决定

- 产品名：**Roost Bot**（仓库、包名、界面统一用小写 `roostbot`）
- 品牌短名：**Roost**
- 中文名：**栖巢**（口语「巢」「回巢」）
- npm scope：`@roost/*`（2026-11-03 实测 `@roost/cli` 返回 404，可用）
- 域名优先级：`roostbot.io`（已确认无解析）→ 备选 `roostbot.dev` / `roostbot.ai` / `roostbot.bot`
- 注意：`roostbot.com` 与 `roostbot.app` 已被占用，营销页不要假设拿到 `.com`

## 为什么是这个名字

- `roost` 是"栖息处"，正好描述"Bot 的家在云上，也在你本地"
- `bot` 让品类一眼可见，不用解释
- 组合词没有明显商标冲突面（裸词 `roost` 在 .ai/.io/.cloud 都已被占，组合反而更安全）
