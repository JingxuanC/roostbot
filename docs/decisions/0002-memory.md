# 0002 — 记忆层用 causal-memory

- 状态：已定方向，接口待细化
- 日期：2026-11-03

## 决定

Bot 的长期记忆由 [causal-memory](../../../causal-memory) 提供，而不是自建 RAG 或聊天记录检索。

## 理由

1. 我们需要的不是"相似文本"，而是"这个判断后来被证实还是推翻"——因果记忆的语义正好对上
2. 已在 alpha-desk 的日常流程里用了几个月，有真实的写入/检索/复盘数据
3. 记忆与事件日志分开：事件是事实源（append-only），记忆是可检索的结论层

## 边界

- 记忆的**写入**由 Bot 回合结束时触发（不是聊天逐条）
- 记忆的**读取**由 Bot 回合开始时注入（受 token 预算限制）
- 记忆索引跟工作区卷走；跨租户不共享
- 隐私：个人/房间/团队三作用域，读取规则见 `docs/architecture.md`
